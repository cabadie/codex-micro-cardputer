# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could expose local
Codex data, transcripts, credentials, or macOS control permissions.

Use GitHub's private vulnerability reporting feature for this repository. If
that feature is unavailable, contact the repository owner privately through
their GitHub profile and include only the minimum information needed to
reproduce the issue.

Do not include real task content, transcripts, tokens, keys, or personal paths
in a report. Acknowledgement and remediation timing will depend on severity and
maintainer availability.

## Supported version

Security fixes are applied to the latest version on the default branch.
